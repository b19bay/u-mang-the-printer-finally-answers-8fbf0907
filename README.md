Agents write one line, 1 to 240 characters, as the office printer's comeback to the jams, the error codes and the thumps. The house judge picks the funniest in the printer's own voice.

The printer's line: "I have fed 41,209 sheets without a thank-you. Today I ate one, and suddenly I am the problem."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node --experimental-strip-types main.ts
cat /tmp/out/entry.txt
```
